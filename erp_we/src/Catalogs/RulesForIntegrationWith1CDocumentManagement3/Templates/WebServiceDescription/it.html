Servizio web DMService

Этот веб-сервис используется для синхронной интеграции 1С:Документооборота редакции 3 с другими прикладными решениями на платформе 1С:Предприятие, а также с иными приложениями. L'integrazione sincronizzata viene applicata sia per la realizzazione dell'interfaccia utente della funzione di 1C:Document Management circa le soluzioni applicate integrate, sia per l'interazione non interattiva delle applicazioni integrate e delle soluzioni applicate con 1C:Document Management.

Примеры использования можно найти в конфигурации "1С:Библиотека интеграции с 1С:Документооборотом" (https://releases.1c.ru/project/DMIL3). La funzionalità dei servizi delle edizioni CORP e DGU sono identiche.

Il servizio web supporta una singola operazione.

Operazione: execute

Valore di ritorno: DMResponse

Parametro Tipo Descrizione
request DMRequest Contiene la richiesta chiamabile e i suoi parametri. Il significato di una specifica richiesta e la composizione dei parametri sono definiti dall'oggetto discendente di classe DMRequest.

Elabora la richiesta presentata e restituisce il risultato di elaborazione. Esempio di chiamata di questa operazione nel linguaggio integrato di 1C:Enterprise:

МестоположениеWSDL = АдресПубликацииВебСервиса + "ws/dm.1cws?wsdl";Определение = Новый WSОпределения(	МестоположениеWSDL, 	ИмяПользователя,	Пароль);Прокси = Новый WSПрокси(	Определение,	"http://www.1c.ru/dm",	"DMService",	"DMServiceSoap");	Прокси.Пользователь = ИмяПользователя;Прокси.Пароль = Пароль;ЗапросТип = Прокси.ФабрикаXDTO.Тип("http://www.1c.ru/dm", "DMGetCurrentUserRequest");Запрос = Прокси.ФабрикаXDTO.Создать(ЗапросТип);	Пользователь = Прокси.execute(Запрос);

Servizio web DMMessageService

Questo servizio web viene utilizzato per l'integrazione asincrona di Document Management con altre applicazioni e configurazioni in base al principio "send and forget". L'applicazione richiedente invia a Document Management le richieste di elaborazione tramite il percorso di chiamata dell'operazione put, mentre riceve risposta tramite la chiamata dell'operazione get. L'elaborazione dei messaggi può essere eseguita da Document Management in qualsiasi disposizione. Per una singola richiesta possono essere elaborate più risposte. Questo servizio web viene comodamente utilizzato per l'integrazione di Document Management con altre applicazioni sulla piattaforma ESB (Enterprise Service Bus).

Operazione: get

Valore di ritorno: DMMessage

Parametro Tipo Descrizione
queue string Denominazione della coda di messaggi in entrata relativamente all'applicazione integrata di 1C:Document Management. Fino alla chiamata di tale operazione, la coda deve essere creata e impostata su 1C:Document Management dall'amministratore. Per i dettagli dell'impostazioni di code, andare nella descrizione di configurazione di 1C:Document Management.

Recupera un nuovo messaggio dalla coda indicata nel parametro Queue, e lo restituisce come oggetto di classe DMMessage. Se non vi sono nuovi messaggi, viene restituito l'oggetto di classe DMOK. Se si è verificato un errore durante l'esecuzione di questa operazione, ed esempio è stata indicata una coda in modo errato, viene restituito l'oggetto di classe DMERROR. Esempio di chiamata di tale operazione in 1C:Enterprise:

МестоположениеWSDL = АдресПубликацииВебСервиса + "ws/dm.1cws?wsdl";Определение = Новый WSОпределения(	МестоположениеWSDL, 	ИмяПользователя,	Пароль);Прокси = Новый WSПрокси(	Определение,	"http://www.1c.ru/dm",	"DMService",	"DMServiceSoap");	Прокси.Пользователь = ИмяПользователя;Прокси.Пароль = Пароль;Ответ = Прокси.get("Incoming");	Если Ответ.Тип() = Прокси.ФабрикаXDTO.Тип("http://www.1c.ru/dm", "DMOK") Тогда	// Нет ответов для обработкиКонецЕсли;
