Servizio web DMService

Questo servizio web viene utilizzato per l'integrazione sincronizzata di 1C:Document Management con altre soluzioni applicate sulla piattaforma 1C:Enterprise e altre applicazioni. L'integrazione sincronizzata viene applicata sia per la realizzazione dell'interfaccia utente della funzione di 1C:Document Management circa le soluzioni applicate integrate, sia per l'interazione non interattiva delle applicazioni integrate e delle soluzioni applicate con 1C:Document Management.

È possibile trovare esempi di utilizzo nella configurazione "Biblioteca di integrazione con 1C:Document Management" (BID), fornita come parte del kit di distribuzione.

Differenza di edizione PROF, CORP e DGU

Funzione di applicazione assente nell'edizione PROF, ad esempio la posta integrata non è supportata neppure tramite servizio web.

Inoltre, il servizio web dell'edizione PROF non supporta l'aggiornamento automatico in background degli attributi degli oggetti collegati (richieste DMGetChangesRequest, DMPutChangesRequest).

La funzionalità dei servizi delle edizioni CORP e DGU sono identiche.

Il servizio web supporta una singola operazione.

Operazione: execute

Valore di ritorno: DMResponse

Parametro Tipo Descrizione
request DMRequest Contiene la richiesta chiamabile e i suoi parametri. Il significato di una specifica richiesta e la composizione dei parametri sono definiti dall'oggetto discendente di classe DMRequest.

Elabora la richiesta presentata e restituisce il risultato di elaborazione. Esempio di chiamata di questa operazione nel linguaggio integrato di 1C:Enterprise:

Servizio web DMMessageService

Questo servizio web viene utilizzato per l'integrazione asincrona di Document Management con altre applicazioni e configurazioni in base al principio "send and forget". L'applicazione richiedente invia a Document Management le richieste di elaborazione tramite il percorso di chiamata dell'operazione put, mentre riceve risposta tramite la chiamata dell'operazione get. L'elaborazione dei messaggi può essere eseguita da Document Management in qualsiasi disposizione. Per una singola richiesta possono essere elaborate più risposte. Questo servizio web viene comodamente utilizzato per l'integrazione di Document Management con altre applicazioni sulla piattaforma ESB (Enterprise Service Bus).

Operazione: get

Valore di ritorno: DMMessage

Parametro Tipo Descrizione
queue string Denominazione della coda di messaggi in entrata relativamente all'applicazione integrata di 1C:Document Management. Fino alla chiamata di tale operazione, la coda deve essere creata e impostata su 1C:Document Management dall'amministratore. Per i dettagli dell'impostazioni di code, andare nella descrizione di configurazione di 1C:Document Management.

Recupera un nuovo messaggio dalla coda indicata nel parametro Queue, e lo restituisce come oggetto di classe DMMessage. Se non vi sono nuovi messaggi, viene restituito l'oggetto di classe DMOK. Se si è verificato un errore durante l'esecuzione di questa operazione, ed esempio è stata indicata una coda in modo errato, viene restituito l'oggetto di classe DMERROR. Esempio di chiamata di tale operazione in 1C:Enterprise:

Classe DMApprovalType

Classe base: DMObject

Descrive la variante di organizzazione di omologazione nel processo aziendale "Omologazione" in Document Management. Свойство ObjectID.ID содержит не GUID, а текстовое значение, соответствующее одному из значений перечисления "Варианты согласования" в Документооборот.

Classe DMGetObjectAdditionalPropertiesRequest

Classe base: DMRequest

Previsto per la ricezione dell'elenco degli attributi aggiuntivi dell'oggetto al fine di spostarli in un modulo o compilare programmaticamente. Sarà restituito l'elenco degli attributi aggiuntivi insieme ai loro valori.

La ricezione degli attributi aggiuntivi è supportata per gli oggetto dei tipi seguenti:

  • Documenti interni (DMInternalDocument)
  • Documenti in entrata (DMIncomingDocument)
  • Documenti in uscita (DMOutgoingDocument)
  • Contraente (DMCorrespondent)
  • File (DMFile)
Proprietà Tipo Obbligatorio Elenco Descrizione
object DMObject Sì Non ci sono

Oggetto di tipo supportabile derivante da DMObject per il quale è necessario ricevere l'elenco degli attributi aggiuntivi. Se in Document Management non è prevista per gli oggetti del tipo fornito la presenza di attributi aggiuntivi, sarà restituito un elenco vuoto.

Per la ricezione dell'elenco degli attributi aggiuntivi del documento del tipo determinato (DMInternalDocument, DMIncomingDocument, DMOutgoingDocument) nei valori della proprietà Object dell'oggetto devono essere compilate le proprietà  ObjectID e DocumentType. Non è richiesta la compilazione delle proprietà restanti.

Per la ricezione dell'elenco degli attributi aggiuntivi del file (DMFile) nel valore della proprietà Object dell'oggetto deve essere compilato il valore ObjectID. Non è richiesta la compilazione delle proprietà restanti.
