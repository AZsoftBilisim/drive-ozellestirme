Configuring an autonomous workstation on your PC

Note: To work offline, install [НазваниеПрограммы]. For more details, see below.

All operations to transfer data to the initial image are performed within a single transaction of the master node database. This is necessary to ensure the consistency of the data transferred to the initial image. However, if other users are actively changing data in the master node infobase, conflicts may arise between the transaction that is creating the initial image and the transactions of other users. In such cases, it is advisable to set the exclusive mode for the master node infobase before creating the initial image.

  1. Create a folder where your standalone workstation infobase will be stored. We recommend creating a folder in My documents.
  2. Open the downloaded archive file Standalone mode.zip to the destination folder.
  3. Start 1C:Enterprise. In the 1C:Enterprise startup window and click Add
  4. Select Add infobase and click Next.
  5. Select This computer or LAN computer and enter the infobase name. We recommend using the same name for your standalone workstation and your infobase.
  6. Specify Infobase subfolder located in the folder you created during step 1, and click Finish.
  7. Click 1C:Enterprise at the top right of the 1C:Enterprise startup window.
    In infobase access window, select the creator of the standalone workstation from the list in the User field. The Password field must remain blank.

 

To start the application, start 1C:Enterprise and select this infobase from the list. To modify the Internet data synchronization parameters, use the Standalone mode command in the Administration section.

Additional details

 

1. How to install or update 1C:Enterprise platform?

To work offline, install [НазваниеПрограммы]. 1C:Enterprise applications are available through a worldwide partner network.

If the application is installed, make sure that 1C:Enterprise version is [ВерсияПлатформы] or higher. To look up the platform version, click Help > About in the menu. If 1C:Enterprise version is older, install the latest version from the 1C website.

2. How to set up an autonomous workplace for other users?

As soon as you have completed the setup procedure above, your standalone workstation will be ready for work. Your account will be granted the administrative rights, identical to the Internet-enabled mode.

To share this standalone workstation with other users, you need to allow these users to sign in to the application. For this, add them to the Users list located in the Administration section. This will grant them access rights identical to the online mode. For more information on user list maintenance and access rights setup, refer to the application documentation.

To allow the users to perform Internet data synchronization without requiring your assistance, you will additionally need to modify the default Internet connection settings. For this, you may use the button "Set up connection..." in the window "Autonomous work" of the section "Administration". In the setup form, specify a user to perform data synchronization. Assign Data synchronization with other programs profile for this user in the Internet-based version of the application.
