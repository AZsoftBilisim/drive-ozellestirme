Procedura di aggiornamento per la nuova versione della piattaforma 1C: Enterprises 8.3

1. Scarica il pacchetto di distribuzione 1C:Enterprise 8.3

Scaricare il pacchetto di distribuzione dell'ultima versione della piattaforma 1C:Enterprise 8.3 nel servizio 1C:Programs Updates. In caso di necessità indicare login e password.

Quindi, selezionare la versione corrente (l'ultima pubblicata ufficialmente) della Piattaforma tecnologica 8.3.

Per scaricare il file cliccare sul collegamento ipertestuale corrispondente al vostro sistema operativo:

  • Piattaforma tecnologica 1C:Enterprise per Windows
  • Piattaforma tecnologica 1C:Enterprise per Linux
  • Client 1C:Enterprise per macOS

Successivamente al collegamento Scaricare pacchetto di distribuzione si apre la finestra di dialogo di salvataggio del file su computer. Ricordare la cartella in cui viene salvato.

2. Installare una nuova versione 1С:Enterprises 8.3

Если у вас операционная система Microsoft Windows, то обратите внимание: для установки приложения пользователь Windows должен обладать правами администратора. Decomprimere il file di archivio scaricato. В папке, в которую распаковали архив, запустите файл Setup.exe и следуйте инструкциям приложения-установщика.

3. Creare una copia di backup dell'infobase

Запустите 1С: Предприятие. Nella finestra che si apre Avvio di 1C:Enterprise indicare e aprire la cartella in cui si trova l'infobase necessaria. Poi copiare il file 1Cv8.1CD in un luogo sicuro.

4. Iniziare con la nuova versione della piattaforma

Utilizzando il pulsante 1C:Enterprise, puoi iniziare a lavorare con l'infobase selezionata sulla nuova versione della piattaforma.
